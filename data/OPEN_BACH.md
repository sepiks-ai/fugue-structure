# Open Bach corpus (data/open_bach.json, data/tx_pieces.json)

`data/open_bach.json` holds notes read from MIDI that LilyPond rendered from the Mutopia Project's engravings
of Bach (https://www.mutopiaproject.org/, sources at https://github.com/MutopiaProject/MutopiaProject,
directory `ftp/BachJS`). Only pieces whose Mutopia licence is Public Domain, Creative Commons Attribution or
Creative Commons Attribution-ShareAlike were used; the Well-Tempered Clavier was left out (it comes from
Rother's edition, below). Because some sources are CC BY-SA, these derived files are shared under
**CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/), crediting the Mutopia Project and the
typesetters named in each source file.

`data/tx_pieces.json` combines it with `data/open_wtc.json` (Kyle Rother's edition of the Well-Tempered
Clavier, CC BY 4.0, OpenUCT) and is shared under CC BY-SA 4.0 for the same reason.

Licences of the Mutopia pieces used: {'Creative Commons Attribution-ShareAlike 3.0': 239, 'Public Domain': 380, 'Creative Commons Attribution 3.0': 36, 'Creative Commons Attribution-ShareAlike 4.0': 28, 'Creative Commons Attribution-ShareAlike 2.5': 14}.
