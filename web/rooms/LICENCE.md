# Room recordings (impulse responses)

Both from the OpenAIR library (Audio Lab, University of York), via the Reverb.js collection
(github.com/andigamesandmusic/Reverb.js), licensed CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0/).
Trimmed to their audible tails and normalised; these files are shared under the same licence.

- `st-andrews-church.wav`: St Andrew's Church. OpenAIR, http://www.openairlib.net/auralizationdb/content/st-andrews-church
- `lady-chapel-st-albans.wav`: Lady Chapel, St Albans Cathedral. OpenAIR, http://www.openairlib.net/auralizationdb/content/lady-chapel-st-albans-cathedral
